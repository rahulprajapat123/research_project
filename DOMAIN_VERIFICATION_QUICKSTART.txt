┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 1: LOGIN TO RESEND                                                   │
└───────────────────────────────────────────────────────────────────────────┘
   → Go to: https://resend.com/login
   → Enter your credentials
   → Access dashboard


┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 2: ADD DOMAIN                                                        │
└───────────────────────────────────────────────────────────────────────────┘
   → Click "Domains" in sidebar
   → Click "Add Domain" button
   → Enter: bridgeaitech.com
   → Click "Add"


┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 3: COPY DNS RECORDS (Resend will show you these)                    │
└───────────────────────────────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────────────────────────┐
   │ Record 1: SPF (Sender Policy Framework)                            │
   ├─────────────────────────────────────────────────────────────────────┤
   │ Type:  TXT                                                          │
   │ Name:  @                                                            │
   │ Value: v=spf1 include:_spf.resend.com ~all                         │
   └─────────────────────────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────────────────────────┐
   │ Record 2: DKIM (DomainKeys Identified Mail)                        │
   ├─────────────────────────────────────────────────────────────────────┤
   │ Type:  TXT                                                          │
   │ Name:  resend._domainkey                                            │
   │ Value: [Long string from Resend - starts with "v=DKIM1; k=rsa;"]   │
   └─────────────────────────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────────────────────────┐
   │ Record 3: DMARC (Optional but recommended)                         │
   ├─────────────────────────────────────────────────────────────────────┤
   │ Type:  TXT                                                          │
   │ Name:  _dmarc                                                       │
   │ Value: v=DMARC1; p=none; rua=mailto:dmarc@bridgeaitech.com         │
   └─────────────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 4: ADD RECORDS TO YOUR DNS PROVIDER                                 │
└───────────────────────────────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────────────────────────┐
   │ CLOUDFLARE                                                          │
   ├─────────────────────────────────────────────────────────────────────┤
   │ 1. Login → Select domain → DNS                                      │
   │ 2. Add record → Type: TXT                                           │
   │ 3. Paste Name and Value from above                                  │
   │ 4. Save (repeat for all 3 records)                                  │
   └─────────────────────────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────────────────────────┐
   │ GODADDY                                                             │
   ├─────────────────────────────────────────────────────────────────────┤
   │ 1. My Products → DNS → Select domain                                │
   │ 2. Records → Add → Type: TXT                                        │
   │ 3. Paste Name and Value                                             │
   │ 4. Save (repeat for all 3 records)                                  │
   └─────────────────────────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────────────────────────┐
   │ NAMECHEAP                                                           │
   ├─────────────────────────────────────────────────────────────────────┤
   │ 1. Domain List → Manage → Advanced DNS                              │
   │ 2. Add New Record → TXT Record                                      │
   │ 3. Paste Host and Value                                             │
   │ 4. Save (repeat for all 3 records)                                  │
   └─────────────────────────────────────────────────────────────────────┘


┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 5: WAIT FOR DNS PROPAGATION                                         │
└───────────────────────────────────────────────────────────────────────────┘
   ⏰ Typical wait time: 15-30 minutes
   🌍 Can take up to 24 hours in rare cases


┌───────────────────────────────────────────────────────────────────────────┐
│ STEP 6: VERIFY DNS RECORDS (Optional but helpful)                        │
└───────────────────────────────────────────────────────────────────────────┘

   → Enter: bridgeaitech.com
   → Select: TXT Lookup
   → You should see your SPF record

   → For DKIM, enter: resend._domainkey.bridgeaitech.com
